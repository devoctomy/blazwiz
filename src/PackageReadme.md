# blazwiz

Part of [blazwiz](https://github.com/devoctomy/blazwiz): a framework for Blazor WebAssembly PWAs that sign in with AWS
Cognito, sync files to S3 with end to end encryption, and work offline.

Create an app with the template (`dotnet new install Devoctomy.Blazwiz.Templates`, then `dotnet new blazwiz`), and
upgrade it by changing `BlazwizVersion` in its `Directory.Packages.props`. See `docs/versioning.md` in the repository
for what counts as a breaking change.
