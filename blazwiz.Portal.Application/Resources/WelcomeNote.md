# Welcome to your notes

This note was created for you the first time you signed in. Edit it, move it into a folder, or delete it once you have had a look around.

## Organising your notes

The **Files** page lists your notes and folders.

- **New note** and **New folder** create them in the selected folder. Click a folder to select it.
- **Drag and drop** a note or folder onto another folder to move it, or onto *All notes* to move it back to the top level.
- Use the buttons on each row to **rename**, **move** or **delete** it. Deleting a folder deletes everything inside it.

## Writing

Notes are written in [Markdown](https://commonmark.org/help/). Select some text and use the toolbar to format it, or type the formatting yourself:

| Type this | To get |
| --- | --- |
| `**bold**` | **bold** |
| `_italic_` | _italic_ |
| `~~strikethrough~~` | ~~strikethrough~~ |
| `` `code` `` | `code` |

Lists and tasks work too:

- [x] Read the welcome note
- [ ] Write your first note
- [ ] Organise notes into folders

> The preview on the right updates as you type. Collapse it with the preview button in the toolbar for more room.

## Saving

Press **Save** (or `Ctrl` + `S`) to save your changes. If you try to leave with unsaved changes, you will be asked what to do with them.

Your notes are stored in this browser, so they are available offline.
